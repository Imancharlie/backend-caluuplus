Import Courses

Upload an Excel or CSV file containing course data. Programs must exist first.

Required Columns:

  • program - Exact program name (must exist)
  • year - Academic year (1, 2, 3, etc.)
  • semester - Semester number (1 or 2)
  • name - Course name
  • code - Course code (e.g., CS101)
